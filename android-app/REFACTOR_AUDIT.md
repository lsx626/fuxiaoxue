# Android 重构与验收记录（2026-10-16～17，未发布）

本轮重点是 Android 的完整使用流程、数据可靠性和界面重做。版本入口仍为 1.2.3 / versionCode 19，不能把本工作区的能力当成既有 Release；未提交、推送或生成正式签名发布包。此前的桌面资料库优化保留。

## 使用体验与结构

- 统一靛蓝、浅灰和明暗主题，重做登录、课程库、课程文件、学习动态、存储、设置和搜索。手机使用四项底部导航；宽度达到 720dp 时切换侧栏与课程网格。
- 截止日期和最近变更移到独立的「动态」，存储和设置使用完整页面。课程列表保留搜索、学期和统计；文件可按名称/目录、状态组合筛选，并切换未读、名称、更新时间排序。
- 文件页提供续读、类型标记、阅读进度和失败原因。课程内同步放在独立底栏，避免悬浮按钮覆盖文件操作；全量重新下载、删除和退出都有影响说明与取消入口。
- 登录支持密码显隐、键盘下一项/提交、完整错误状态与离线入口。密码不进入 saved instance state，只有主动勾选时才存入 Keystore 加密配置。
- 预览返回保留课程筛选与搜索结果，搜索进入文档后返回仍是原关键词。旧的单体 `HomeScreen` 拆为导航壳与功能页；共用组件、展示规则、阅读几何和后台结果策略独立测试。
- 同步详情采用可滚动底部面板，显示课程/文件进度、累计完成字节与平均速率，支持停止。未完整同步与需要重新登录均保留明确入口。

## 主要问题及处理

| 发现的问题 | 处理与回归证据 |
| --- | --- |
| 已发布建库遗漏 `files.error`，文件写入报错 | v5 只加列，v4 升级设备测试保留路径、状态和阅读进度；升级失败回滚 |
| 自动登录丢失 `_canvas_session` 名称；没有密码时不能读旧资料 | 会话名称贯穿 UI/Worker，已登录账号可先进入离线库；认证成功仍自动同步；`AppViewModelLifecycleTest` |
| 会话在同步中途被另一个登录任务替换 | 会话应用、手动/后台同步、重试和删除共用 `SyncGate`，退出取消任务 |
| 停止同步时阻塞网络读仍继续 | 可取消 OkHttp 调用关闭 socket，响应在成功、异常和取消路径均释放；取消任务等待读取回调释放文件后才退出互斥区，避免立即重启同步时两个任务交错写同一个断点；`CancellableHttpTest` |
| 并发下载等全部结束后才写结果、更新进度 | 有界通道 + 3 个工作协程，逐项消费完成结果，写库串行；取消向全部任务传播 |
| 原子落盘前先删除旧副本 | 同目录替换移动，失败保留旧副本与断点；校验 206 的 Content-Range 起点，远端版本变化清理旧断点 |
| 下载失败、刷新签名地址和索引吞掉取消/鉴权异常 | 取消原样传播，401 熔断；403/404 更新签名地址，单文件重试刷新元数据与锁定状态 |
| 不完整/损坏的列表可能冒充完整列表 | 课程/文件/作业关键记录严格校验，整批失败保留本地数据；设备合成响应测试覆盖 |
| 来源失败仍显示成功，空作业列表不清旧待办 | 来源错误计入不完整课程；只有作业完整成功才能替换待办，包括成功空列表 |
| 教师锁定文件更新记录时遗失本地路径 | 保留旧路径与阅读进度，界面显示锁定，续读和搜索排除锁定项 |
| 删除未验证真实路径、删除失败仍丢记录 | 限制在应用下载树中，磁盘删除成功后再删记录；远端已删的本地文件仍可在存储页管理 |
| 删除后迟到的阅读回调重建孤立进度 | 进度写入以文件仍存在为条件，文件身份绑定回调，防翻文件后串写 |
| FTS4 更新未删掉旧行，搜索重复且旧正文仍命中 | 无类型亲和性的 file_id 显式转整数删除；v6 清理旧重复索引，查询去重，重复索引设备测试 |
| 搜索摘要显示中文预分词串；FTS 失败无降级 | v6 新增原文缓存（每文件最多 64 Ki 字符），摘要取原文；异常时文件名 LIKE 降级，`%`/`_` 按字面匹配 |
| PDF 资源关闭/取消存在竞态 | `produceState` 持有资源，IO 中打开与预取比例，取消后 finally 关闭，页面操作串行化 |
| 跳页/主显示页判定偏移，窄屏阅读控制挤压 | 用实际可见面积判页，恢复后才写进度；跳页包含 header；两行固定控制条与输入校验 |
| 本轮原生 PDF 截图发现两排工具栏被 Surface 叠放 | 加入纵向布局容器；设备用例比较两排控件的实际边界，防止“可点击但视觉重叠”的回归 |
| 媒体反复进入 READY 时重置续播位置 | 只 seek 一次，监听先于 prepare，翻文件释放旧播放器；停止/进度/循环/音量独立触控行 |
| 文本一次布局巨大、编码不一致、查找定位不到行 | BOM/UTF-8/GB18030 解码；最多读取 2 MB、8k 字符懒加载块；正文查找定位到命中行 |
| 图片缺加载状态、错误页对比度差、只靠手势缩放 | 主题化画布、加载/错误状态、固定缩放/复位、拖动边界；GIF/SVG 接入正式 Coil 解码器并设备验证 |
| HTML 链接可包含不安全 scheme | 本地富文本解析，移除 script/style 文本，链接只允许用户主动打开 http(s)，不执行脚本 |
| ZIP 类文件无可读视图 | ZIP/JAR/APK/EPUB 只浏览目录，最多 1000 项，如实说明截断；不解压、不运行 |
| 后台失败不断重试/通知，恢复的密码密文失效 | 有限指数重试、错误通知去重、无密码不调度；Keystore 解密失败清理失效密文 |

## 数据与兼容性

当前 schema 为 **v6**。已发布 1.2.3 为 v4：v5 补缺失错误列，v6 加 `file_text_cache` 并清理重复的搜索索引行；不删除课程、文件、截止日期或阅读记录，不移动既有下载目录。索引/原文缓存是派生数据，旧文件由每轮同步最多 100 项逐步回填。

仍使用 SQLiteOpenHelper、OkHttp、WorkManager、POI 和 Media3，没有切换 Room 或更改认证协议。会话头只发给 eLearning 的精确 HTTPS 主机，签名下载跨站重定向不携带学校 Cookie/CSRF。没有新增遥测、云上传或真实资料测试。

旧格式夹具可复现生成：在安装 Word/PowerPoint 的 Windows 上，用桌面项目的 Python 依赖环境运行 `python android-app/tools/generate_office_fixtures.py --output <测试产物目录>`。脚本从空白合成文档产生带 Alice/Score 表格、图片、格式化文字和两页幻灯片的文件，关闭宏、隐藏文档窗口，只关闭自身创建的 Office 实例。将 `legacy.doc`、`modern.docx`、`legacy.ppt` 推入专用测试应用的 `files/fixtures/` 后再执行插桩。二进制夹具属于本机生成物，不入库；没有 Office 的环境仍会显式跳过这两个外部夹具用例。
